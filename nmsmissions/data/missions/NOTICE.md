# Mission completion tables

The YAML files in this directory come from
[okranger1777/nms-mission-progress](https://github.com/okranger1777/nms-mission-progress)
(MIT License, Copyright (c) 2025 Ok Ranger). See `LICENSE.okranger`.

Each row is a mission id and the progress value seen on a finished save
(`^MISSION_ID: number`). Chain order and prerequisites live in `../chains.yaml`
and were written for this viewer. They are not part of that project.
